# דוח פעילות יומית — מרכז העורף

כלי שמייצר דוח HTML יומי מקבצי Excel של גדודים.

## דרישות

- Python 3.9+
- חבילות: `pandas`, `openpyxl`

התקנה (פעם אחת):
```bash
pip install -r requirements.txt
```

## מבנה התיקייה

```
reports-tool/
├── run.py              ← הסקריפט הראשי
├── config.json         ← מילון נושאים והגדרות
├── template.html       ← תבנית עיצוב הדוח
├── requirements.txt    ← רשימת חבילות Python
├── reports/            ← תיקיית פלט (נוצרת אוטומטית)
└── README.md
```

## שימוש בסיסי

הסקריפט מקבל **תיקייה** עם קבצי האקסל ומפיק קובץ HTML.

```bash
# דוח להיום
python run.py /path/to/data/folder

# דוח לתאריך ספציפי
python run.py /path/to/data/folder --date 2026-05-27

# פלט לקובץ מותאם
python run.py /path/to/data/folder --date 2026-05-27 --out custom_report.html
```

## פורמט שמות הקבצים

הסקריפט מזהה יחידות לפי שני דפוסים:
- `<מספר>_export*.xlsx` — לגדודים שיש להם מספר
- `<שם-עברי>_export*.xlsx` — לגופים שמזוהים בשם (כמו מפקדות)

דוגמאות שיתפסו:
- `240_export.xlsx` → גדוד 240
- `241_export_v2.xlsx` → גדוד 241
- `999_export_final.xlsx` → גדוד 999
- `מפקדה_מחוז_export.xlsx` → מפקדה_מחוז

קבצים שלא מתאימים לדפוס יידלגו. **אין צורך לעדכן את הסקריפט כשנוסף גדוד חדש** — פשוט שים את הקובץ בתיקייה.

## מה הדוח מכיל

1. **KPI עליון** — סה"כ פניות, טופלו, לא נענו, בהמתנה + אחוז טיפול
2. **פילוח לפי יחידה** — כל גדוד וסטטיסטיקות שלו
3. **פילוח לפי איש צוות** — דירוג ביצועים
4. **נושאי פנייה TOP 15** — גרף עמודות
5. **קטגוריות-על** — משפחה, רגשי, תעסוקה, רווחה, זכויות, שירות
6. **מטריצת איש צוות × נושא** — heatmap
7. **פניות לאורך זמן** — מופיע רק כשהטווח גדול מ-7 ימים. דליי יום/שבוע/חודש נבחרים אוטומטית לפי אורך הטווח

## עריכת מילון הנושאים

`config.json` שולט בעיצוב הסמנטי. שני שדות עיקריים:

### `active_values`
ערכים בעמודה בוליאנית שנחשבים "נושא פעיל בפנייה":
```json
"active_values": ["נדרש", "הגיש כבר"]
```

### `topics`
מיפוי מעמודה לתווית עברית ולקטגוריית-על:
```json
"birth_grant": { "label": "מענק לידה", "category": "משפחה" }
```

אם נוספה עמודה חדשה בקבצי האקסל — הוסף ערך ב-`config.json` והיא תופיע בדוח.
אם רוצים להסתיר נושא — הסר אותו מ-`config.json`.

## ניקוי נתונים שהסקריפט עושה אוטומטית

- מסיר רווחים מיותרים משמות אנשי צוות (" רוני פסאי" ↔ "רוני פסאי")
- מאחד טעויות כתיב בעמודת הסטטוס
- מתעלם משורות ללא תאריך / ללא איש צוות בפילוח לפי אנשים
- מתעלם מקבצי lock של Excel (`~$*.xlsx`)

## הפצת הדוח

ה-HTML הוא **קובץ עצמאי** — כל ה-CSS והפונטים בתוכו. אפשר:
- לפתוח בכל דפדפן
- לשלוח בווטסאפ / מייל
- להדפיס ל-PDF דרך הדפדפן (Ctrl+P → Save as PDF)
- לפתוח בנייד

## הוספת גדוד חדש בעתיד

**שום שינוי בקוד.** רק:
1. שים את הקובץ בתיקיית הנתונים, בפורמט `<מספר>_export*.xlsx` או `<שם-עברי>_export*.xlsx`
2. הרץ את הסקריפט

## פתרון בעיות

**"לא נמצאו קבצים"** → ודא שיש קבצים בפורמט הנכון בתיקייה.

**"תאריך לא תקין"** → השתמש בפורמט `YYYY-MM-DD`, לדוגמה `2026-05-27`.

**נושא לא מופיע בדוח** → ודא שהוא מוגדר ב-`config.json` ושערכי העמודה הם "נדרש" או "הגיש כבר".

**איש צוות לא מופיע** → ודא ששמו לא ריק ושיש לו תאריך תקין בעמודת "תאריך".
